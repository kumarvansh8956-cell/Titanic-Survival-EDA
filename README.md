# Titanic Survival Analysis

## Project Overview
Performed exploratory data analysis (EDA) on the Titanic dataset using Pandas.

## Skills Used
- Python
- Pandas
- NumPy

## Analysis Performed
- Data Cleaning
- Missing Value Detection
- Survival Analysis
- Passenger Class Analysis
- Fare Analysis
- Correlation Analysis

## Key Findings
- First-class passengers had higher survival rates.
- Higher ticket fares were associated with higher survival.
- Passenger class showed a stronger relationship with survival than age.
