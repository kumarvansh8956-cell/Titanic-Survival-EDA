# 🚢 Titanic Survival EDA

Exploratory Data Analysis of the Titanic passenger dataset using **Python, Pandas, NumPy, Matplotlib, and Seaborn**.

## 📌 Objective

Analyze the Titanic dataset to understand the factors associated with passenger survival through data cleaning, statistical analysis, and visualization.

## 🛠️ Tools & Libraries

* Python
* Pandas
* NumPy
* Matplotlib
* Seaborn
* Jupyter Notebook

## 🧹 Data Cleaning

* Identified and handled missing values.
* Converted `age` and `fare` into appropriate numeric formats.
* Used passenger titles to improve missing-age handling.
* Used passenger class to handle missing fare values.
* Removed duplicate records.
* Verified the dataset after cleaning.

## 📊 Analysis & Visualizations

The project explores:

* Overall survival rate
* Gender vs survival
* Passenger class vs survival
* Age distribution
* Fare distribution
* Family size vs survival
* Embarkation port vs survival
* Numerical correlation
* Gender × passenger class
* Age and fare vs survival

## 🔥 Key Findings

* Overall survival rate: **38.46%**
* Female survival rate: **72.90%**
* Male survival rate: **19.28%**
* 1st class had the highest number of survivors.
* Cherbourg (`C`) had the highest survival rate among the embarkation ports.
* Fare showed a positive correlation with survival.
